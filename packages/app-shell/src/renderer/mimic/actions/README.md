# 拟态 · 动作模型目录

把动作放进本目录（或其子目录）即可被自动识别。**默认全部禁用** —— 需要在
「设置 → 拟态 → 动作模型」里逐条启用，并**为每条写触发提示词**。

## 目录结构

每个动作为一个子目录，内含 `action.json` + 贴图/精灵图：

```
actions/
  wave/
    action.json
    sheet.png
  stretch/
    action.json
    sheet.png
```

## action.json 格式

```json
{
  "name": "挥手打招呼",
  "desc": "向用户挥手，表示问候或告别",
  "trigger": "当用户说你好、再见、早上好，或桌宠刚出现在桌面上时触发",
  "duration": 1600,
  "cooldown": 8000,
  "priority": 5,
  "sheet": {
    "frameWidth": 128,
    "frameHeight": 128,
    "frames": 6,
    "fps": 10,
    "loop": false
  }
}
```

- `name`：界面显示名
- `desc`：一句话说明（给人看）
- **`trigger`**：**触发提示词**（给模型看）。写清"什么情况下该做这个动作"。
  项目会把它注入模型的可用动作清单，并**要求模型遵守**：只有满足条件才触发。
- `duration`：单次播放毫秒数
- `cooldown`：两次触发之间的最小间隔（毫秒），防止刷屏
- `priority`：同时满足多个条件时，数字大的优先
- `sheet`：精灵图切分参数（同人物模型）

## 内置动作

- `blink`：眨眼（idle 时随机触发，默认启用）
- `wave`：挥手
- `nod`：点头
- `think`：思考（进入推理时）
- `sleep`：打盹（长时间无交互）

## 触发提示词的写法（重要）

触发提示词会原样交给模型，因此：

- 写**条件**，不写"总是"：「当用户问技术问题时」而不是「用户说话时」
- 一条动作**只做一件事**，避免"既能打招呼又能思考"
- 用可观察的信号描述：用户说了什么、屏幕出现了什么、上一步做了什么
- 没有把握时宁可不写 —— 触发太频繁会干扰对话

## 冲突与优先级

多个动作同时满足条件时：`priority` 大者胜；相同则 `cooldown` 已过者胜；
仍相同则随机。同一动作在 `cooldown` 内不重复触发。
