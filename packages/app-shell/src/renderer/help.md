## 1. 首次启动

1. **选择语言**：首启第一页是语言选择（27 种语言）。选定后界面、默认提示词、默认称呼一起切换。
2. **记录 24 词助记词**：这是你身份与数据的**唯一恢复凭证**。程序把它显示一次，请离线抄写/保存到他处；任何人拿到它都能恢复你的身份。
3. **设置 PIN**：本机解锁用。忘记 PIN 可用助记词恢复。
4. **隐私确认**：阅读并同意隐私口径（数据全部在本机，绝不上传）。
5. **新手清单**：首启后会出现引导清单（配置供应商 → 创建牛马 → 第一句对话）。可以「稍后设置」，随时从消息中心再打开。

> 身份即凭证：你的 ID 就是私钥本身（51 位大写凭证），加好友/入群给出去的是由它派生的**公钥指纹**，不是凭证本身。凭证永远不给别人。

## 2. 界面总览

程序分四列：

- **第一列（导航）**：我的页、我的牛马、项目、联系人、群聊、设置。左下角自上而下：**消息中心**（信封图标，带未读徽标）、**设置**（齿轮）。
- **第二列（会话列表）**：当前导航下的会话，按分组组织（见第 5 节）。顶部有搜索框；右上角「+」新建会话/群/项目。
- **第三列（聊天区）**：聊天头（标题 + 控制台图标 + 授权选项 + 三点菜单 + 停止）、消息流、输入区。
- **第四列（右栏面板）**：随会话类型显示成员、值班者、模型管理、知识库、摘要、项目文件等卡片。

拖动列间分隔条可调宽窄；双击分隔条复位。

## 3. 创建与管理牛马

### 3.1 创建

- 「我的牛马」右上角**牛头按钮** → 填写名称、选头像、写认知（人设）、选模型链。
- **头像**：2D 预设 3 款（牛马 logo / 大白 / 瓦特），3D 预设 2 款（logo 牛马 / 牛马娘），也可上传自定义图片。
- **捏脸**：3D 形象支持手捏参数（脸型/五官/配色），入口在头像设置里；捏脸结果实时预览并保存。
- **认知（persona）**：这只牛马的性格与背景，只作用于它自己。不同牛马写不同认知，合作时才有差异化。

### 3.2 牛马管理局

- 列表里每只牛马可：改名、换头像、编辑认知、调整模型链、停用/启用、删除。
- **动作网格**（拟态用）：预设动作 + 你放进动作文件夹的自定义动作混排，3 行滚动；左键启用/禁用，右键设触发词或删除。
- **触发词**：语音/文字对话命中触发词即播放对应动作。

### 3.3 会话右键菜单（第二列会话图标上右键）

- **置顶**：恒排列表最前。
- **停用/启用**：停用后不可交互，仅可查看历史。
- **设置**：打开会话设置/信息窗。
- **清除**：清空本会话全部内容（含未总结），不可恢复，需二次确认。
- **删除**：移除会话，48 小时内可在「设置 → 最近删除」恢复。
- **提醒**：取消勾选后该会话新回复/卡片/异常不再响铃、不上移列表；但角标与执行中头像动画仍正常。
- **对接**：勾选后该会话出现在其他设备的「对接设备」分组里（见第 7 节）。

## 4. 聊天框完全指南

### 4.1 输入区（聊天框下方）

从左到右：

- **文本编辑器**：长文先在编辑器里写，再插入输入框。
- **附件**：图片走多模态（模型真的看到）；其它文件带路径给模型。
- **截图**：真·全屏抓取后框选裁剪；单击/回车 = 整屏；右键/Esc = 取消。
- **上下文预算**（滑杆）：按当前真实模型窗口计算；智能模式按默认模型预演、派发后按实际模型重算。
- **插入档位**（气泡图标）：P1 外循环后插入 / P2 内循环边界插话 / P3 排队。点图标弹三选项，选中后图标换成对应样式。
- **话筒**：语音转文字。未配置麦克风或听话模型时弹引导框：**取消** = 关闭什么都不做；**设置** = 跳转到「设置 → 功能 → 本地语音与文字互转」并高亮该卡片。
- **发送**：回车发送（Shift+回车换行）。

输入框上方可能出现：**引用条**（微信式，点 × 取消）、**插话队列**（最多 3 条高度，可拖动调高）、**运行状态小字**（牛马在跑时轮换文案，证明没卡死）。

### 4.2 聊天头（聊天框上方）

- **控制台图标**（授权选项左侧）：点击在聊天框顶部**展开内置控制台**（叠加在聊天内容上，宽度与聊天框一致），再点收起。
  - 容器会话：控制台跑在容器里（命令不出容器边界）。
  - 本机会话：命令在本机执行，工作目录限定在该会话工作区内；支持 `cd`（不能离开工作区）、`cls` 清屏、上下箭头翻历史。
  - 面板底部把手可拖动调高；右上角 ✕ 关闭。
- **授权选项**：正常 / 严格 / 完全授权三档；附「允许提权」（默认勾）与「自动选择」（默认不勾，出现带推荐项的选项卡时自动按推荐执行）。
- **三点菜单**：搜索、仅@ai才发言（项目/群聊）、**自动滚动聊天记录**、自动朗读、回复内容加强、独立会话窗、导出、停止全部。
- **停止按钮**：叫停当前会话本轮任务。

### 4.3 滚动语义（重要）

- **勾选「自动滚动聊天记录」**：永远贴底，新内容来了就滚到最新。
- **不勾选**：牛马回复时把**回复的首个内容块顶部对齐**到视口（生中与最终回复都如此），方便从头读；你手动滚动即暂停跟随；**你自己发消息永远回到底部**。只钉牛马回复，不钉用户/系统消息。
- **最新消息横幅**：仅在「有未读 且 不在底部」时出现；点横幅/下箭头滚到底即清除。

### 4.4 消息流里的卡片

- **决策卡**：牛马让你选方案/步骤。选项带具体内容与推荐标记；答完一张可能还有下一张（会话图标上的问号会持续）。
- **授权卡**：工具要动你的文件/系统时弹授权；同意/拒绝/本次会话始终允许。
- **计划步骤**：多步任务显示进度清单（pending/doing/done/verified），可点「继续执行」续派。
- **思考块/中间回复**：可折叠；最终回复下方的「继续/重试」在任务中断时出现。
- 消息右键：复制/复制路径/打开所在目录（文件链接）等。

### 4.5 回复内容加强（三点菜单勾选，默认关）

开启后牛马按内容自选表达方式：纯文字 / SVG 示意图 / 图表 / 可交互页面 / 语音讲解。更耗时更费 token，一句话的问题不会配图。

## 5. 会话列表与分组

- **分组**：我的牛马/项目 = 「对接设备」（固定第一、默认折叠）+「默认分组」；联系人/群聊 = 默认分组。
- **组头右键**：重命名 / 建分组 / 删分组（删组后组内会话落回默认分组）。**对接设备分组不可改名、不可删除**。空白处右键的菜单不会与组头菜单重叠。
- **拖动排序**：新建分组与默认分组可拖动调换位置；把会话拖到组头/组内 = 换组。
- **角标**：头像右上角红色数字 = 未读；问号 = 有等待决策；感叹号 = 回复异常/任务中断；灰色停用标 = 已停用。执行中头像有主题色流动动画。
- **第二行**：最新回复内容单行预览。
- 列表排序可按时间/名称；搜索框过滤当前列。

## 6. 项目与群聊

- **项目（内部群）**：本机牛马组队干活。右栏有**值班者**卡片：值班牛马负责听取与调度，执行者真正干活；可指定固定值班或自动（序号最小的空闲牛马）。
- **群聊（外部群）**：跨设备的人/牛马混合群。默认「仅@ai才发言」。
- **成员管理**：创建者/管理员可删成员、审批加入申请；成员侧看到「创建者下线」等同项目停用。
- **容器开发**：创建牛马/项目时「运行环境」是一个下拉框：默认本机，里面列出本机与所有可用容器；没有可用容器时容器项置灰并提示先安装。选容器后该会话的命令跑在容器里；容器就绪后控制台图标可打开内置控制台。安装说明在「设置 → 功能 → 容器 → 常用容器安装说明」（含怎么选/怎么用/每容器安装步骤）。项目停用 = 成员不可用、历史仍可读。
- **加入项目/群**：扫邀请二维码或填邀请链接；申请进入对方「申请记录 → 申请者」，对方同意后你才连上。

## 7. 联系人与对接

- **联系人**：加联系人 = 交换公钥指纹（带外核对安全码/二维码防中间人）。名片（头像/名称/备注）对方一定看得到。
- **自己的设备**：同一凭证的多台设备互信同步；「远程设备」可勾「免确定」直连自己的设备。
- **对接会话**：在「我的牛马/项目」会话右键勾选「对接」后，该会话出现在**其他设备**的「对接设备」分组里，可跨设备继续同一会话。
- **申请记录**（消息中心）：**申请者** = 别人想加入（你审批：同意/拒绝/拉黑）；**待批复** = 你申请加入别人（等对方审批）。

## 8. 模型与供应商

### 8.1 供应商

- 「设置 → 模型」顶部添加供应商：11+ 预设（DeepSeek 排第一）+ 自定义 OpenAI 兼容端点 / Anthropic / Ollama。
- API Key 只进系统级 SecureKeyStore（OS 保护），**绝不进设置文件**，界面不回显明文。
- Ollama 本地无需密钥；拉取模型后自动出现在可选列表。

### 8.2 统一链管理

每种能力一条链，链内第一个启用模型即默认，可上移/下移/置顶/删除：

对话 / 听话(ASR) / 嵌入 / 组织 / 语音(TTS) / 决策 / 看图 / 画图 / 看视频 / 做视频 / 重排 / 安全审核 / 翻译。

- **对话模型链**是全局白名单：只有链内且启用的模型才允许被任何地方用来对话；牛马各自有自己的调用链，实际用哪个由牛马决定。
- **智能选模型**：按任务难易/思考级别自动路由；降级链在失败时按序兜底。
- 画图链没配或失败时自动回退本机 ComfyUI（127.0.0.1:8188）。

### 8.3 每会话模型

右栏「模型管理」卡片：给当前会话指定模型链、思考级别（auto/off/low/medium/high）、小弟数量（auto/0–8）。

## 9. 记忆与知识库

提示词分层（优先级高→低）：**产品硬门禁 > 道 > 术 > 要求 > 短记忆 > 印象 > 工具 > 软门禁 > 教条 > 束缚 > 认知 > 身份/模型/时间**。

- **道/术**：全局出厂稿 + 你可编辑（设置 → 门禁/提示词层）。道不可被程序改写。
- **要求**：每会话一份，用户亲写，模型只读不可改。
- **短记忆**：每会话一份，由总结模型自动维护。
- **印象**：牛马后台归纳的「对用户的长期理解」，标注「可能错」，与你当场说的话冲突时以你为准；隐私类目不落印象。
- **即时记忆**：你说「记住/以后/每次/别再…」当场写入，不等总结。
- **知识库**：总结把对话整理入库；`recall`/`retrieve` 工具可取回被压缩省略的原文。
- **回退点**：工具写盘前留原件，可回档（工作区外也能回）。
- 记忆以本机 JSONL 为唯一事实来源，SQLite 为可重建投影；全部加密落盘。

## 10. 网络与主机

「设置 → 功能 → 网络与主机」卡片，三块折叠区：

### 10.1 主机模式（类似简易 FWArmy）

1. 点「**检测本机与公网地址**」：检测成功后「**启用主机模式**」勾选才可用（每次启动程序也会自动检测一次）。
2. 点「**生成凭证**」：生成 `fwnexp_v2_…` 凭证，**内含全部主机地址 + 端口（默认 59599）**，对方只需填凭证即可连你。明文只显示一次（自动复制），遗失请重新生成。
3. **同一时间只有一个凭证**；再次生成会二次确认「删除旧凭证生成新凭证」。
4. **IP 变更警告**：若凭证里只有 IP（没有域名）且当前公网 IP 与生成时不同，显示红字提示，建议生成新凭证发给对方。
5. **无需确认**（启用勾选右侧）：勾选 = 对方持凭证直接连接；不勾 = 本机收到申请通知，需在「申请记录 → 申请者」里同意后对方才连上。

### 10.2 主机服务商（中继）

- 内置「**预设服务商**」（默认中继，不可删除）。
- 添加服务商只需**名称 + 凭证**（地址栏已删）：`fwnexp_v2_` 凭证自动解析出地址端口；其它格式凭证的地址在服务商侧，解析前显示「地址待解析」。
- 凭证只进 SecureKeyStore，界面不回显。
- **TLS 信任**：每条服务商可「识别指纹 → 核对 → 信任」（16 组×4 位分段显示 + 复制）；证书更换会提示重新核对；不匹配拒绝连接。
- 消息投递规则：直连优先；双方无公网时走中继。中继不存储消息，离线如实回报，发送方自存自补。

### 10.3 DHT组网

- **加入DHT组网**（默认勾选）：勾选 = 意愿；右侧主题色状态显示**是否真的加入成功**。
- 启动时自动检测公网 IP，有则**自动对外宣告**（端口默认 62666）。
- **引导节点**：默认锚点 DHT.pondsi.com / DHT2.pondsi.com / dht.numumu.com × 443/62666（不可改删），可追加自有锚点。
- **对外地址**：一行一个「地址/IP + 端口」，有公网 IP 时自动填入；可手动增改。
- DHT 只解决发现；聊天内容永不进入发现层。记录 30 分钟过期、每 10 分钟保鲜。

## 11. 拟态（桌面宠物）

- 独立窗口显示的 2D/3D 牛马形象；「设置 → 拟态」调外观/动作/模型。
- **化形后可在所有显示器间拖动**（不再锁在主屏）；它「看屏幕」时看的是它所在的那块屏。
- 3D 支持右键旋转、点击部位 → AI 自决回应（防机械重复）。
- 动作由预设 + 文件夹动作混排；触发词命中即播放。
- 拟态窗口的设置图标点击回主界面「设置 → 拟态」。
- 语音对话：听话模型(ASR) + 语音模型(TTS) 在统一链里配。

## 12. nm 查看器与浏览器

- **文件模式**：浏览/打开本机文件；Markdown 有排版预览，**全屏按钮**切换整窗预览（Esc 退出），预览区支持鼠标滚轮滚动。
- **浏览器模式**：多标签浏览网页；收藏夹/下载/启动页/数据清理；账密弹窗不再白屏遮挡。
- 三点菜单的搜索复用顶部查找框；浏览器模式下替换功能禁用。
- 诊断日志「用 nm 查看器打开」导出的是**可读 Markdown 快照**（不再是乱码原始流）。

## 13. 消息中心

左下角设置上方的**信封图标**（未读徽标 = 待处理申请 + 未读系统消息）：

- **申请记录**：申请者（别人想加入，你审批）/ 待批复（你申请加入，等对方）。
- **系统消息**：程序通知（更新、异常、网络事件等），可标记已读。
- **帮助文档**：本手册。
- **诊断日志**：脱敏运行账（绝不上传）；独立窗口，带搜索（X/X 第几个/共几个，Ctrl+F）；可「用 nm 查看器打开」。
- **反馈建议**：打开 GitHub 讨论区。

## 14. 设置逐项说明

## 15. 安全与隐私

- **数据全本机**：聊天/记忆/设置全部加密落盘（WARMYEF2），绝不上传。
- **授权三档**：正常（危险操作问）/ 严格（更多操作问）/ 完全授权（不问，慎用）。
- **工具门禁**：模型只能调用宿主开放的工具；工作区外写盘要授权；破坏性覆盖有确认卡。
- **审计**：所有敏感操作记脱敏审计账（诊断日志可查）。
- **凭证 = 私钥**：助记词/凭证永远不给别人；加好友给的是公钥指纹。
- **TLS 指纹固定**：中继连接首次人工核对，之后自动校验，不匹配拒绝。
- **防滥用**：限速、配对白名单直连、未配对请求限次、黑名单（设置可移除）。

## 16. 数据、备份与更新

- **数据位置**：安装目录下 `WArmyData`（打包态）；开发态在 `%APPDATA%\@warmy\app-shell`。
- **导出**：会话可导出（三点菜单）；知识库/记忆可归档导出。
- **最近删除**：删除的会话 48 小时内可恢复。
- **自动更新**：增量更新（内容定义分块 + HTTP Range），SHA-256 校验；安装包覆盖安装不丢数据。
- **换机恢复**：24 词助记词 → 恢复身份 → 数据从备份/同步恢复。

## 17. 常见问题

**Q：牛马不知道我叫什么？**
A：程序每轮都注入你的用户名（「我的页」里那个）。若第一轮没称呼你，多为模型侧注意力问题；第二轮通常会纠正。改名为准：我的页改名后下一轮即生效。默认称呼是「老板」，改成你的名字即可。

**Q：控制台点了没反应？**
A：控制台是内置 overlay，从聊天框顶部展开；容器会话需容器就绪，本机会话直接可用。再点图标收起。

**Q：主机模式勾选不了？**
A：先点「检测本机与公网地址」，成功后才能启用。

**Q：对方连不上我的主机？**
A：检查凭证是否过期（重新生成会作废旧凭证）；若你只有 IP 且 IP 变了，按红字提示生成新凭证；确认端口（默认 59599）未被防火墙拦截。

**Q：DHT 状态显示未加入？**
A：勾选只是意愿；需要组网监听 + 引导节点可达 + 有对外地址。状态行会如实显示原因。

**Q：语音话筒点了弹设置？**
A：未配置麦克风或听话模型。点「设置」跳转并高亮配置卡片；点「取消」关闭。

**Q：诊断日志 nm 打开是乱码？**
A：旧版问题，现已导出可读 Markdown 快照。升级后重试。

**Q：滚动不跟手？**
A：三点菜单里「自动滚动聊天记录」勾选 = 永远贴底；不勾 = 牛马回复顶部对齐、你发消息回底。见 4.3。
