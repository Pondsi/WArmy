# WArmy 帮助文档

> 本文件随程序内置，从「消息 → 帮助文档」打开（优先 nm 查看器，未启用则系统默认程序）。

## 快速上手
1. 首启选择语言 → 记录 24 词助记词（唯一恢复凭证，务必离线保存）→ 设 PIN。
2. 左列「我的牛马」右上角牛头按钮创建牛马；第二列会话图标右键可 置顶/停用/设置/清除/删除。
3. 聊天框下方滑杆为上下文预算，按当前真实模型窗口计算；智能模式按默认模型预演、派发后按实际模型重算。

## 会话右键菜单
- 置顶：恒排在列表最前。
- 停用/启用：停用后不可交互，仅可查看历史。
- 设置：打开会话设置/信息窗。
- 清除：清空本会话全部内容（含未复盘），不可恢复，需二次确认。
- 删除：移除会话，48 小时内可在「设置 → 最近删除」恢复。
- 提醒：取消勾选后该会话新回复/卡片/异常不再响铃、不在左列出现圆点、不上移列表；但会话上的新回复/问号/感叹号图标与执行中头像流动效果仍正常。

## 记忆与复盘
- 记忆以本机 JSONL 为唯一事实来源，SQLite 为可重建投影。
- 复盘/归档会把对话整理进知识库；「清除」会连未复盘内容一起删除。

## 网络与中继
- DHT 只解决发现；消息投递走凭据通道（被扩网凭据 + TLS 指纹固定）。
- 默认锚点：DHT.pondsi.com / DHT2.pondsi.com × 443/62666。
- 中继不存储消息；离线如实回报，发送方自存自补。

## 诊断与反馈
- 「消息 → 诊断日志」查看脱敏运行账（绝不上传）。
- 「消息 → 反馈建议」打开 GitHub 讨论区。
