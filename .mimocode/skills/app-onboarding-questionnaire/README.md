# app-onboarding-questionnaire（已安装）

来源：https://github.com/adamlyttleapps/claude-skill-app-onboarding-questionnaire （MIT）

用途：设计高转化的首启引导。本项目把它与 NN/g《Onboarding Tutorials vs. Contextual Help》
的结论结合，落到桌面端：

- 用 **pull revelation（页内教练标记）**，不用阻塞式弹窗教程；
- 每一步**必须让用户真的去做**，并看到回报（不是只读一段话）；
- 可随时**跳过**，且之后能**重新调出**（设置 → 关于/帮助里的「重新查看引导」）；
- 进度可见（第 n/N 步），文案以**用户收益**开头，不讲功能清单；
- 不要求用户记忆——帮助内容贴在当下这一步旁边。
