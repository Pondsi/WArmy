## 7. 追加（2026-10-25）：知识库 / 模型可改提示词的互斥放置

用户口径：**规范是特殊的，不和其他知识库/提示词互斥；除规范（以及只能由人写的提示词）外，知识库与模型可改提示词互斥——同一内容只能出现在一处。归档时一条内容只能放一个位置；提示词旧内容要替换时，先把旧内容写进知识库，再写新内容。规范（以及只能由人写的提示词）允许和知识库/其它提示词重复。**

### 7.1 定义

- **互斥组**：知识库（会话 / 内部 / 私密）+ 模型自动改写的提示词（`术`、`印象`）。
- **豁免**：`规范`、`道`、`教条`、`束缚`、`认知` —— 不做跨库去重，允许重复。
- **归档摘要 / 派生概要**（`laiYuan` = `archive:*` / `derived:*`）是**溯源记录**，不是待放置的内容条目，不参与互斥；否则摘要里必然有用户原话，术/印象会被永远判成重复。

### 7.2 代码落点

- `packages/app-shell/src/prompt-placement.ts`（纯函数）：
  - `shiTongYiNeiRong()`：去空白/标点/大小写后相同，或短句（≥8 字）被长句完整包含；
  - `zhaoHuChiWeiZhi()`：返回命中的 `knowledge` / `shu` / `yinXiang`；
  - `HU_CHI_TI_SHI_CENG = ['shu','yinXiang']`，`BU_HU_CHI_TI_SHI_CENG = ['guifan','dao','jiaotiao','shufu','renzhi']`。
- `guiNaShu`（术）：
  - 候选先查知识库/印象；命中就不写术；
  - 自动段旧条目被同义新说法替换 ⇒ 旧条目先迁知识库；
  - 段内超过 20 条要裁最旧 ⇒ 先迁知识库；迁不动就保留（绝不静默丢）。
- `zhengLiYinXiang`（印象）：同上；知识库/术命中就不写印象；裁剪/替换先迁知识库。
- 迁出目标：非敏感 → 内部库；敏感 → 私密库；**不允许落某个群的会话库**；落不下就保留原条目。
- 归档提炼：`guoLuHuChiShiTi()` 在写知识库前过滤掉与“已有知识条目 / 本次偏好 / 术 / 印象”重复的事件；两处归档入口都接。
- `knowledge_add`：内容已在术/印象 ⇒ 不重复写知识库，并在工具回报里说明。
- 模型提示词：归档整理与印象整理都加【放置规则】；`knowledge_add` 工具说明同步写入口径。
