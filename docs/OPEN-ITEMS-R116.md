## B. 仍需你环境 / 账号 / 拍板

1. **nm 多显示器 / 任务栏实机目检**：需要你的三屏组合；按 `OPEN-ITEMS-R102.md` A2/A3 的步骤操作即可。
2. **4K 物理屏**：本机没有 4K 屏，CDP 五视口只验 DOM。
3. **真实第二设备 / IM 真实账号**：需要第二台机器、一次性测试号或 bot token（不要密码）。
4. **代码签名 / macOS 公证**：Windows SignPath Foundation / macOS Developer ID 仍需你申请或拍板；未签名安装器的 SmartScreen/Gatekeeper 提示不会消失。
5. **真实 TTS / 画图 / 视频供应商**：需要可用 Key 和额度；当前只有链式回退与本地/已有供应商。
6. **远程页下载管理器**：现在下载走 Chromium 默认行为，没有保存位置/进度/打开文件 UI。要做的话请拍板：默认下载目录自动保存，还是每次弹保存框。
7. **全量加密边界**：workspace、外部项目目录、截图/字体、Chromium 缓存、账号密钥仍保持明确的明文/独立保护边界；运行期明文工作副本在异常断电时仍可能残留到下次登录清理。
