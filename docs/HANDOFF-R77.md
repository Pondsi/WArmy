## 1. 外部 IM 调研（未改渠道实现）

当前实现：Telegram（Bot API 长轮询）、Slack（REST 频道轮询，无 Socket Mode）、Discord（REST 轮询，无 Gateway）、Matrix（/sync）可用；飞书、企业微信、钉钉只有 SDK 检查、没有建立连接与接收回调；QQ/WhatsApp 未实现。个人微信是 iLink 扫码 + getupdates 长轮询。

主流产品的普通用户路径（2026-10-24 官方资料）：

| 产品 | 飞书 | 钉钉 | 企微 | QQ | Telegram / Slack / Discord | WhatsApp |
|---|---|---|---|---|---|---|
| OpenClaw | 扫码自动建 Bot（也支持手填） | 插件：建应用、权限、发布、凭据 | 外部插件：BotID/Secret | 官方插件：开放平台建 Bot | BotFather / 建 App+OAuth 邀请 / 建 Bot+intents | 扫“关联设备”二维码（Baileys 路线） |
| 扣子 | 授权发布，平台托管 | 建应用+凭据 | 扫码+管理员审核 | 未确证 | 建 Bot 交 token / 建 App | Meta 商业配置 |
| Dify | 官方插件 Webhook | 群发送工具，不是双向机器人 | 官方插件 | 社区 LangBot | 官方插件，多数需要 token/Webhook | 官方插件+Meta |
| n8n | 社区/自建 | 社区 | 社区 | 社区 | Slack Cloud 可 OAuth；TG 需 token | Meta 配置 |

结论：**扫码代建、OAuth、平台托管回调**可以减少手填，但没有“免凭据接管个人账号”的官方通用方案；企业应用授权也不等于个人号登录。建议后续做“扫码/授权向导 + 自动发现频道 + 连通性检测”，仅在高级配置暴露 ID/key，并优先补齐飞书/企微/钉钉的真实长连接。来源见 `docs/HANDOFF-NEXT.md` 顶部。

## 2. 个人微信（本轮已改）

- **扫码更快**：状态请求 8 秒超时；超时保持 wait/scaned 继续轮询，不再把网络超时当失败；支持 `need_verifycode`（界面输入验证码后继续）、`scaned_but_redirect`（只接受 `*.weixin.qq.com` 官方主机，拒绝伪造域名/路径/端口）、`binded_redirect`、`verify_code_blocked`。
- **确认后立即回报**：凭据加密保存后立刻返回“扫码已确认，正在连接…”，连接在线/失败通过 `warmy:sheJiaoZhuangTai` 异步广播；界面分行显示“已扫码待确认 / 已保存连接中 / 已连接 / 失败”，关窗后的迟到结果不再改界面。
- **收不到消息的根因**：多账号改造后，保存时逐个账号加密凭据，读回却只解密旧的顶层字段，连接拿到密文地址/令牌。现在读全量解密、写唯一入口统一加密；旧嵌套密文有界解包，解不开就拒绝联网。重复保存不会二次加密。
- **接收不被模型阻塞**：适配器长轮询正常结束立即续拉，错误才有限退避；主进程按会话有界队列（256 全局 / 64 每会话）串行处理，同一微信的多条消息有序、不同会话不互锁；断开/重连后的旧队列任务不再派发或回信。
- **昵称/备注**：官方确认响应确认包含 `bot_token / ilink_bot_id / ilink_user_id / baseurl`，**没有昵称字段**。界面显示“备注 · ID”，空备注只显示 ID；备注可手动保存（最长 80 字），不会冒充微信昵称。
- **改名**：设置中“链接微信（个人）”改为“微信（个人）”。
- **安全**：凭据加密失败即整次保存失败；旧实例整态保存不能覆盖主进程社交凭据；错误/审计不含 token、URL、二维码。

## 3. 语音识别（本轮已改）

按用户 2026-10-24 口径：

- **本地语音必须安装完整运行时 + ASR + TTS 才能启用**；启用失败返回原因并保留原选择，不会写“已启用”。
- **启用即只用本地**：本地 ASR/TTS 失败直接报错，不自动改云端、不自动取消勾选、不自检改动选择。取消勾选后才走听话模型链。
- **未启用时**：话筒与音频附件统一按“设置 → 模型 → 听话模型”配置顺序逐个尝试（去重/去禁用，不按名字过滤、不重排）；同一模型标准 `/audio/transcriptions` 失败后兼容 chat 协议；全部失败逐个列出原因。Ollama 无音频端点明确拒绝，不把音频塞给聊天模型编造。
- **识别语言**：只作用于聊天框话筒；`auto` 不传，选具体语言显式传；音频附件永远不传语言，由 ASR 判断。本地 paraformer 只支持中英，显式非中英语种会如实报限制。
- **音频格式**：新增 `yin-pin-wav.ts`，在主进程用隐藏的沙箱 BrowserWindow `decodeAudioData` 把 MP3/M4A/OGG/WebM/FLAC 转 16k 单声道 WAV；解码失败的附件直接报错，不上传、不进入后续聊天。附件转化后的 `dataUrl` 优先于原路径。
- **话筒**：读取设置里选定的输入设备（之前一直用系统默认）；录音器创建失败/录音中异常会释放音轨并提示具体原因。
- **界面**：安装进度用主题色进度条；删除按钮文案改为“删除”；移除“仅使用本机语音服务”第二开关；文案 10 语言同步（安装后才可启用、关闭后按链顺序）。
