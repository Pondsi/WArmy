# WArmy（无限牛马）隐私政策

**版本**：1.0 · **生效日期**：以仓库该文件的提交时间为准
**适用产品**：WArmy / Workhorse Army / 无限牛马（桌面端、移动端预览页）
**维护者**：Pondsi（开源项目作者，非公司实体）

> 本政策用**可核对的事实**写成，而不是免责套话。全文分三部分：
> **一、我们如何处理数据**；**二、我们的能力范围与努力**；**三、我们无法保证与可能疏漏之处**。
> 首次启动选择语言后必须阅读并同意本政策；可在「设置 → 关于」查看全文或**撤销同意**（撤销后软件退出，下次启动须重新同意）。

---

## 摘要（30 秒版）

1. 本软件**没有中心服务器**：我们不运营账号系统，也没有可以接收你数据的后端。
2. 你的会话、文件、知识库、记忆、密钥默认**只保存在你自己的电脑上**。
3. 我们**不会、也无法**获取你使用软件时的任何信息，**除非你自己主动提交到本项目的 GitHub Issue/PR**。
4. 软件在**你主动配置或操作**时才可能联网（检查更新、你填写的模型服务、你开启的组网）。
5. 开源、可审计、可自行编译核对；审计日志只在本机、可随时清空。

# 一、我们如何处理数据

## 1.1 数据存储位置

| 数据 | 存放位置 | 是否上传 |
|------|----------|----------|
| 会话与消息 | 本机用户数据目录（JSONL 日志，唯一事实来源） | 否 |
| 项目 / 群 / 看板 | 本机 `groups.json`、`board.jsonl` | 否 |
| 知识库与归档 | 本机 `knowledge.json`、`archives.jsonl` | 否 |
| 记忆索引（SQLite / 向量） | 本机；可由 JSONL 全量重建 | 否 |
| 模型 API 密钥 | 本机；优先系统安全存储（Windows DPAPI / macOS Keychain） | 否 |
| 身份私钥 | 本机**加密**存储（信封加密：DEK + 系统钥匙串/口令包裹） | 否 |
| 审计日志 | 本机 `audit/audit.jsonl` | **绝不**上传 |
| 设置与界面状态 | 本机 `settings.json`、`window-state.json` | 否 |

## 1.2 只在以下情况才会联网

**全部由你主动触发或主动配置**：

| 场景 | 目的地 | 发送内容 |
|------|--------|----------|
| 检查更新 | GitHub Releases API / 原始 feed | 版本查询，不含任何个人数据 |
| 使用云端模型 | **你自己**填写的模型服务商 API | 由你决定发送的对话内容与提示词 |
| 组网协作 | 你与对端设备之间的直连 / 你配置的中继 | 群消息与协议握手；作者不参与、无中继服务器 |
| 提交反馈 | GitHub Issues（你手动提交） | 仅你愿意公开的内容 |

> 我们不使用第三方统计 SDK，不做用户画像，不做 A/B 埋点回传。

## 1.3 身份与凭证

- 身份为**本机生成**的密钥对（Ed25519），唯一凭证是**指纹**（可理解为"公钥的短标识"）。
- 私钥**不以明文出现在界面**，也不离开本机；界面只展示指纹，供你复制给他人核对。
- 设备 ID 为 17 位数字，首次使用时生成并固定保存；**配置文件被删除 = 身份丢失**（等同首次使用，会生成新 ID）。你可以通过**身份备份（JSON + 口令）**在任意设备上恢复原身份。
- 组网（点对点）用端到端加密会话；**作者既不居中转存，也无法解密**你们的通信内容。

## 1.4 你的控制权

- 可**清空**会话/审计日志，可删除知识库条目，可**撤销隐私同意**（软件退出，须重新同意）。
- 可**导出**对话为 Markdown、导出身份备份、导出模型成本 CSV。
- 可**随时卸载**：删除用户数据目录即彻底移除本地数据（不可恢复）。

# 二、我们的能力范围与努力

## 2.1 我们做到了什么

1. **开源可审计**：源代码公开，任何人可自行检查、编译、比对二进制。
2. **本地优先**：核心功能（聊天、项目、看板、知识库、记忆检索）**不需要联网**即可使用。
3. **审计不外出**：审计日志仅落本机且可清空。
4. **密钥最小暴露**：优先系统安全存储；开发模式下的明文存储必须显式开启且会被标记。
5. **权限分级**：工具/脚本调用分「常规（首次审核）」与「严格（每次授权）」，工作区外写入需授权。
6. **诚实状态**：容器未就绪、端口绑定失败、更新失败等一律如实告知，**不假装成功**。
7. **无静默行为**：不静默改端口、不静默降级到本机执行、不静默上传。

## 2.2 我们的努力方向

- 减少任何"默认联网"的可能，把联网都做成显式动作；
- 让"数据在哪、谁能看到"在界面上**看得见**；
- 发现缺陷后优先修复并公开说明（见仓库 CHANGELOG / Release Notes）。

# 三、我们无法保证与可能疏漏之处

这一节是本政策**最重要**的部分。请如实理解边界：

## 3.1 我们无法保证的

| 情形 | 说明 |
|------|------|
| **你的设备被入侵** | 若操作系统账号、磁盘或输入法被控制，本软件无法阻止密钥与数据被窃取。 |
| **你安装的第三方插件/脚本** | 插件在你的权限下运行，其行为不由我们控制；请只安装可信来源。 |
| **第三方模型服务商** | 你把内容发给云端模型时，适用**该服务商**自己的隐私政策，我们无法约束。 |
| **你自己公开的内容** | 提交到 GitHub Issue/PR 的内容是公开的，请自行脱敏（勿贴密钥、真实姓名、内部地址）。 |
| **你开启的组网对端** | 与你组网的设备及其持有者属于你的信任范围；我们无法替你判断对端是否可信。 |
| **不可抗力与法律程序** | 若依法被要求披露，我们只能披露**我们持有的信息**；而纯本地数据我们通常**并不持有**。 |

## 3.2 我们可能疏漏的地方

- **实现缺陷**：任何软件都可能有未发现的漏洞（例如加密细节、权限绕过、日志脱敏不全）。
- **文案与实现不一致**：若界面说明与实际行为有出入，以**代码**为准，并请提交 Issue 让我们修正。
- **依赖链风险**：我们依赖开源库（Electron、Node 生态等），其自身缺陷可能影响本软件。
- **平台差异**：不同操作系统（Windows/macOS/Linux）在密钥保护、沙箱、权限弹窗上表现不同，我们尽力覆盖但无法穷尽。
- **AI 输出不可预测**：模型可能产生错误或不当内容；请把它当作**辅助工具**，关键决策由人复核。

## 3.3 我们的承诺

- 发现影响隐私的缺陷，我们会**优先修复**并在发布说明中写明；
- 我们**不会**为了让功能好用而偷偷扩大数据收集范围；
- 若未来计划引入任何需要联网上传的功能，会**先更新本政策**并在界面显式征求同意。
