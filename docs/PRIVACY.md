# WArmy / 无限牛马 隐私政策（Privacy Policy）

**生效说明**：本软件为本地优先桌面应用。首次启动选择语言后，你必须阅读并同意本政策才能使用；可在「设置 → 关于」中查看全文，也可撤销同意（撤销后软件将退出，下次启动需重新同意）。

---

## 1. 我们是谁

本软件（WArmy / Workhorse Army / 无限牛马）由 Pondsi 开源维护，**没有中心服务器**，不运营账号体系，也不收集你的使用遥测。

## 2. 数据存在哪里

你的会话、项目、知识库、记忆、设置、身份密钥等数据默认保存在**你本机**的用户数据目录（如 Windows 的 Electron `userData`）。我们无法读取这些文件。

## 3. 我们不会做什么

- 不上传聊天记录、文件内容、模型密钥、审计日志到作者服务器（**因为我们没有这样的服务器**）。
- 不在后台静默统计你的使用行为。
- 不把你的身份私钥明文展示或发送到网络（私钥在本机加密存储；界面展示的是指纹等公开标识）。

## 4. 你可能主动产生的对外流量

仅在**你主动配置或操作**时，软件才可能访问第三方，例如：

| 场景 | 目的地 | 说明 |
|------|--------|------|
| 检查更新 | GitHub Releases API / raw.githubusercontent.com | 查询版本与安装包 |
| 使用云端模型 | 你配置的模型供应商 API | 由你填写 base URL 与密钥 |
| 组网协作 | 你与对端设备之间的连接 | 默认本地/LAN；无作者中继时我们看不到内容 |
| 问题反馈 | GitHub Issues（你主动提交） | 仅包含你愿意公开的内容 |

**密钥**：优先使用系统安全存储（如 Windows DPAPI）。开发模式下若启用明文存储，仅限本机调试。

## 5. 我们的能力范围与努力

- 代码开源，可审计；更新包提供校验和。
- 默认最小权限：不主动开端口对外服务，除非你开启组网。
- 审计日志仅本机、可清除；**绝不上传**。
- 组网身份采用本机生成的密钥与指纹；邀请可撤销。

## 6. 我们无法保证 / 可能疏漏之处

- **无中心服务器 ≠ 绝对安全**：若你的电脑被入侵、系统账号被接管、或你安装了恶意插件/脚本，本软件无法代为防护。
- **模型供应商**：你把内容发给第三方模型 API 时，适用该供应商自己的隐私政策，我们无法控制。
- **开源协作**：你提交到 GitHub 的 Issue/PR 会公开；请自行脱敏。
- **实现疏漏**：软件可能存在未发现的缺陷；欢迎通过仓库反馈。我们会在能力范围内修复，但不对由此产生的间接损失作担保（详见 LICENSE 免责条款）。
- **法律要求**：若未来因法律程序必须披露，我们只能披露我们持有的信息——而对纯本地数据，我们通常**不持有**。

## 7. 儿童与敏感数据

本软件面向具备相应法律责任能力的用户。请勿在未评估风险的情况下将高度敏感数据交给不可信插件或模型服务。

## 8. 撤销同意

在「设置 → 关于」中可**撤销对本隐私政策的同意**。确认后软件将退出；再次打开时必须重新阅读并同意才能使用。
