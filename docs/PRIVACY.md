## 30 秒摘要

1. **没有服务器端账号系统**，维护者也**不运营任何能接收你数据的自有后端**。
2. 会话、项目、记忆、知识库、审计日志默认**只保存在你的电脑上**；除你主动发到 GitHub 或邮箱的内容外，维护者不持有你的个人数据。
3. 这些本机文件**多数默认没有加密**，依赖你的操作系统账户与磁盘加密；只有身份私钥、助记词、模型 API Key、社交密码优先使用系统安全存储（不可用时会被明确标记）。
4. 软件只在**你主动操作或主动配置**时联网；联网清单逐项列在第 3 节。
5. 模型与 API Key 由你自备（BYO）。云端模型会收到你选择发送的内容，并按**该服务商**的政策处理。
6. FWArmy 是**可选、独立、可自建**的中继程序，维护者不运营它；它只转发密文、不落盘消息，但能看到元数据。
7. 微信 iLink、企微、Telegram、飞书等第三方 IM 的消息会经过对应平台。
8. **助记词丢失后，任何人都无法替你恢复，包括维护者**；没有"账号找回"，也没有客服后门。
9. 联系方式见文末第 18 节（两个邮箱 + GitHub 仓库地址）。

## 1. 谁在处理你的数据

| 角色 | 是谁 | 处理什么 |
|------|------|----------|
| 本机数据的控制者 | **你** | 会话、文件、记忆、知识库、凭据等都在你的设备上，由你决定保存、导出、删除 |
| 开源项目维护者 | **Pondsi（个人）** | 不接收本机数据；只处理你主动通过 GitHub Issue/PR 或电子邮件发来的内容 |
| 第三方服务 | 你选择并配置的服务商 | 模型服务商、GitHub、npm、Hugging Face、腾讯微信/iLink、你使用的中继运营者等，各自按其政策处理 |

需要明确的三点：

- **没有服务器端账号系统。** 应用里的"账号"只是本机的一份加密配置文件（`auth/vault.json` 与 `identity/identity.json`），不是任何在线服务上的账户；维护者没有你的账号、密码或助记词。
- **维护者不是你的受托处理者（processor）。** 本机处理完全发生在你的设备上，维护者既不参与也无法访问；如果你代表组织部署本软件，你就是该部署的控制者。
- **第三方服务各自负责。** 当你把内容发给云端模型、IM 平台或别人的中继时，是**你**在向它们提供数据；它们是否记录、训练、跨境传输，由它们自己的条款与隐私政策决定。

## 2. 本机数据清单

默认用户数据目录（可在启动时用 `--user-data-dir=` 覆盖）：

| 系统 | 默认路径 |
|------|----------|
| Windows | `%APPDATA%\@warmy\app-shell` |
| macOS | `~/Library/Application Support/@warmy/app-shell` |
| Linux | `${XDG_CONFIG_HOME:-~/.config}/@warmy/app-shell` |

| 数据 | 典型位置 | 内容 | 会自动离开设备吗 | 默认是否加密 |
|------|----------|------|------------------|--------------|
| 会话与消息 | `memory/`（JSONL 为唯一事实来源） | 你说过的话、模型回复、附件引用、时间与会话 ID | 否（除非该轮调用云端模型） | **否，明文** |
| 记忆索引 | `memory/`、`memory-runtime/`（SQLite / 向量） | 由日志生成的检索投影，可由 JSONL 重建 | 否 | **否，明文** |
| 项目 / 群 / 成员 / 看板 | `groups.json`、`board/`、`plans.json` | 群与项目台账、成员、任务卡、项目 MEMORY | 否（组网时按你的选择发给对端） | **否，明文** |
| 知识库与归档 | `knowledge/`、`archive/archives.jsonl` | 实体、事件、证据锚点（会话/内部/私密三层）、归档摘要与锚点 | 否（归档摘要生成时可能发给归档模型；检索命中后可能作为上下文发给模型） | **否，明文** |
| 审计日志 | `audit/audit.jsonl` | 操作名、时间、会话 ID、模型 ID、错误摘要、文件路径等 | **绝不自动上传** | **否，明文** |
| 设置与网络 | `settings.json`、`profile.json`、`net.json`、`net-bindings.json`、`nodes.json`、`peers.json`、`bus/`、`assets.json` | 界面偏好、模型配置、服务器列表、会话与网络绑定 | 否 | **否，明文**（社交密码字段除外） |
| 检查点 / 半成品 / 回收站 | `checkpoints/`、`board-carry.json`、`trash.json` | 文件检查点、未完成任务草稿、最近删除索引 | 否 | **否，明文** |
| 模型 API Key | 由 `secure-keys` 管理 | 各模型服务商的 Key | 否（只发给你填写的服务商） | **是**，系统安全存储 |
| 身份私钥 | `identity/identity.json` | Ed25519 私钥（PKCS8） | 否 | **是**：AES-256-GCM，DEK 由系统钥匙串或口令（scrypt）包裹 |
| 助记词与本机账户 | `auth/vault.json` | 24 词助记词、身份种子、PIN 包裹、自动登录包裹 | 否 | **是**：主密钥由助记词经 PBKDF2-HMAC-SHA512 派生；PIN 另存一份包裹 |
| 社交平台凭据 | `settings.json` 中的 `enc:v1:` 字段 | 邮箱/网站/钱包密码、机器人 token 等 | 否（只发给对应平台） | **通常是**；系统保护不可用时会**明确标记为 `plain`**，不冒充加密 |
| 启动与诊断日志 | `warmy-boot.log`、`updates/` | 启动步骤、崩溃原因、更新下载临时文件 | 否 | **否，明文** |

关于加密，必须说清楚：

- **只有上表标注"是"的项目默认加密。** 会话、记忆、知识库、项目、看板、审计日志都是明文文件；能读到你系统账户的人或程序，也能读它们。
- 系统安全存储（Windows DPAPI / macOS Keychain / Linux libsecret）绑定**操作系统账户**，不绑定整台机器；同一账户下运行的恶意程序可以解密。域环境下，AD 还可能托管 DPAPI 密钥，组织管理员理论上可解。
- 身份私钥即使文件被单独拷走也无法直接使用；但如果你设置了身份口令，**口令忘记 = 身份无法解开**，没有重置。
- 建议开启全盘加密（BitLocker / FileVault / LUKS）、使用强系统账户口令，并锁屏。

## 3. 什么时候会联网

| # | 场景 | 触发方式 | 目的地 | 发出什么 | 对方可能留存什么 |
|---|------|----------|--------|----------|------------------|
| 1 | 云端模型对话 | 你发消息、调用工具、让牛马执行任务 | **你自己填写**的模型服务商 `baseURL` | 系统提示词、对话、你选择的附件/图片、工具输出、记忆或知识库摘录 | 由该服务商决定（请求日志、滥用监控、是否训练等） |
| 2 | 本机 Ollama | 你选择本机模型 | 默认 `http://127.0.0.1:11434` | 同上 | 不出本机（除非你把地址改成远程） |
| 3 | 特殊模型（嵌入 / ASR / TTS / 摘要） | 你配置并启用 | 你配置的服务商或本机 | 需要处理的文本或音频 | 由该服务商决定 |
| 4 | 检查更新 | **打开「关于」页会自动检查**；也可手动点「检查更新」 | `api.github.com`、npm registry | 当前版本查询；**不含**设备 ID、助记词、会话内容 | GitHub / npm 的访问日志（含 IP） |
| 5 | 技能 / 插件市场 | 你搜索或安装 | `api.github.com`、`raw.githubusercontent.com`、npm registry | 仓库名、查询、下载请求 | 对应平台的访问日志（含 IP） |
| 6 | 本地语音模型下载 | 你安装本地语音 | Hugging Face（镜像优先、官方兜底） | 模型文件请求 | 对应平台的访问日志（含 IP） |
| 7 | 局域网 / 公网组网 | 你启用组网、添加对端 | 你的对端设备；你指定的 STUN / 端口映射服务 | 握手、名册、端到端加密的消息 | 对端与你指定的服务可能看到 IP、时间、大小 |
| 8 | FWArmy 中继 | 你添加并选用中继 | 你或第三方运行的中继服务器 | 端到端加密的信封 + DID/时间等元数据 | 内存队列最长 30 秒；凭据哈希、统计、运行日志会落盘（见第 5 节） |
| 9 | 微信 iLink / 企微 / Telegram / 飞书 | 你扫码或填写凭据并连接 | 腾讯、Telegram、飞书等平台服务器 | 消息、联系人/会话标识、机器人 token | 由平台决定；平台可能限流、风控、保留记录 |
| 10 | 外部链接 / 内置浏览 | 你点击链接 | 目标网站 | 常规 HTTP 请求（IP、User-Agent 等） | 由目标网站决定 |
| 11 | GitHub Issue / 邮件 | 你主动提交 | GitHub、你的邮件服务商 | 你写的内容与附件 | 公开（Issue）或双方邮箱留存 |

**不会发生的事：**

- 不使用第三方统计 SDK、广告 SDK、用户画像、A/B 埋点回传。
- 不集成自动上传的崩溃上报 SDK；崩溃原因只写本机 `warmy-boot.log`，操作系统可能另留本机崩溃转储，我们不上传、不读取。
- 不在后台静默上传会话、文件、知识库、审计日志。
- 不把 API Key、助记词、身份私钥发给维护者或任何"统计服务"。

> "本地优先"不等于"永远离线"：一旦你让牛马调用云端模型，发给该模型的内容就已经离开本机。

## 4. 模型与 API Key（BYO）

- **服务商、地址、模型都由你选。** 应用不附带共享密钥，也不代理你的模型请求。
- **Key 只发给你填写的地址。** 保存时优先使用系统安全存储；系统保护不可用时**拒绝写明文**（开发环境只有显式设置 `WARMY_ALLOW_PLAINTEXT_KEYS=1` 才允许，并会打上 `plain` 标记）。
- **Key 不会发给维护者。** 但会作为请求鉴权信息（通常是 `Authorization` 头，部分协议用其他头）发给你配置的服务商；该服务商可能记录请求、做滥用检测、按自己的条款用于训练。请先读它的隐私政策。
- **费用与配额是你的。** 欠费、限流、封号、区域限制由服务商处理；删除本机 Key 不会自动吊销服务商侧的 Key，请到服务商控制台吊销/轮换。
- **发送内容可能很广。** 除对话外，还可能包括附件、图片、工具执行结果、知识库/记忆摘录、系统提示词。不要把助记词、私钥、身份证号、他人隐私等放进去。
- **本机 Ollama 默认不出网。** 如果你把地址改成局域网或公网机器，数据就会离开本机，按那台机器的规则处理。

## 5. 可选中继 FWArmy

FWArmy 是**独立于 WArmy 仓库的可选中继程序**，可以自己运行，也可以使用别人运行的中继。**维护者不运营任何公共中继服务。**

它**不做**什么：

- 不保存消息正文：队列只在内存，单条 ≤64KB、每收件人 ≤50 条、TTL 30 秒，取走即删。
- 不解析信封：消息是端到端加密的，服务器没有收件人的私钥，拿不到明文。
- 不写入消息到磁盘：代码中没有把信封落盘的路径。

它**能看到/能做**什么（必须如实知道）：

- 看到元数据：谁（DID 公钥）、从哪个 IP、什么时候、消息多大、用了哪个凭据、发了多少请求/流量。
- 拒绝服务、丢包、延迟、重放旧信封；如果客户端不核对指纹，它还能替换公钥做中间人。
- 记录凭据哈希、限额、日/月/年统计与运行日志（默认 5MB 轮转），这些会落盘；运行日志按代码只记方法/路径/状态/耗时/凭据哈希前缀，不记 query、正文或凭据明文，但连接层仍能看到 IP。

因此：

- **公网使用请自行配置 TLS**（反向代理或等效方案），否则元数据在传输链路上可能被看到。
- **带外核对身份指纹**（安全码/二维码），不要只信中继返回的公钥。
- **不要把管理面暴露到公网**：FWArmy 管理页只允许本机回环访问；同机其他进程仍可能调用管理接口，别把服务器放在多人共用机器上。
- 如果你运行中继，你就是该服务的运营者，需要自行遵守所在地区关于服务器、通信、内容、备案/许可与滥用的规定；维护者不替你承担这些义务。

## 6. 微信 / iLink 等第三方 IM

- 连接微信 iLink（`ilinkai.weixin.qq.com`）需要你用微信扫码授权；平台会返回机器人 token 与 bot id，这些凭据优先加密保存在本机（系统保护不可用时会明确标记为明文）。
- 你与联系人之间的消息会**经过腾讯的服务器**，适用微信/腾讯的隐私政策与平台规则；维护者不参与，也无法读取。
- iLink 当前是"一个微信号一个 Bot、与创建者 1:1、回信需带 context、平台可能静默限流"的通道，**不保证送达、不保证不被限制**；平台接口变更可能导致功能失效。
- 群聊/外部群内容可能被本机归档进知识库；归档发生在本机，但其中可能包含他人的个人信息，导入与使用前请确认你有相应权利。
- 断开方式：在应用内移除该连接/凭据，并在微信或其他平台侧解除授权。只删除本机凭据不等于平台侧已解绑。

企微智能机器人、Telegram、飞书等通道同理：消息经过对应平台，按平台政策处理。

## 7. 日志、审计、记忆、知识库

- **审计日志**（`audit/audit.jsonl`）：记录操作名、时间、会话 ID、模型 ID、错误摘要、文件路径等，**只在本机，绝不上传**，可在界面清空或直接删除文件。它通常不记录消息正文，但错误信息可能包含你粘贴过的片段；如果要把日志发给别人，请先脱敏。
- **记忆**：只追加的 JSONL 是唯一事实来源，SQLite/向量只是可重建的投影。记忆包含你说过的话与模型回复全文；检索命中后，相关片段会作为上下文发给模型。
- **知识库**：保存你手动存入或从归档提取的实体、事件与证据锚点（会话/内部/私密三层）。它可能包含你与他人对话中的个人信息；检索命中后，相关条目可能作为上下文发给模型。归档摘要可能由你配置的归档模型生成；若该模型在云端，相关对话会发给该服务商。
- **最近删除**：删除的会话进入 `trash.json`，**48 小时内可恢复**，超时自动永久清理；你也可以立即清空。
- **启动日志**：`warmy-boot.log` 记录启动步骤、渲染/子进程退出原因等，用于本机排障；不上传。

## 8. 崩溃、诊断与更新

- **崩溃**：没有自动上传的崩溃上报 SDK。未捕获异常、渲染进程/子进程退出原因写入本机 `warmy-boot.log`；操作系统或 Electron 可能在本机保留崩溃转储，由系统管理，我们不上传也不读取。
- **你主动发日志**：请先删除用户名、主目录路径、内网地址、API Key、助记词、聊天原文等敏感信息。GitHub Issue 是公开的。
- **更新检查**：打开「关于」页会自动检查一次，也可以手动点「检查更新」；请求只包含版本查询，**不包含**设备 ID、助记词、会话内容。请求必然会让 GitHub / npm 看到你的 IP。
- **更新下载**：按发布源提供的 SHA-256 与大小校验，校验失败会删除半成品；当前版本**不自动安装**，安装步骤以发布页说明为准。
- **更新源可配置**：`settings.json` 的 `updateFeedUrl` 或环境变量 `WARMY_UPDATE_FEED_URL`；如果你指向第三方源，该源会看到你的请求。

## 9. 我们不做的事

- 不出售、不出租、不"共享"（按 CCPA 定义）你的个人信息；我们也没有收集到可供出售的信息。
- 不做广告投放、用户画像、跨站追踪、A/B 实验回传。
- 不运营服务器端账号，不提供"云端备份"，不提供"账号找回"。
- 不在代码中设置维护者远程读取你数据的通道；代码开源，可自行审计与编译比对。
- 不把审计日志、会话、知识库上传到任何维护者控制的端点。

## 10. 处理目的与法律基础（GDPR / UK GDPR）

| 场景 | 目的 | 法律基础 | 说明 |
|------|------|----------|------|
| 本机运行与本地存储 | 提供软件功能 | 不涉及维护者处理 | 数据在你设备上，由你控制 |
| 首次启动条款同意 | 取得使用授权、满足透明度要求 | 同意（Art. 6(1)(a)） | 可随时撤销；撤销后应用退出 |
| GitHub Issue / 邮件 | 答复问题、修缺陷、维护项目 | 你主动提供（同意）/ 维护者的合法利益（Art. 6(1)(f)） | 公开内容会被所有人看到 |
| 检查更新 | 安全更新与版本兼容 | 合法利益（Art. 6(1)(f)）或你的主动操作 | 只查版本，数据最小化 |

## 15. 安全措施与已知边界

**已做的：**

- 本地优先，默认不上传会话/记忆/知识库/审计。
- 身份私钥 AES-256-GCM 加密，DEK 由系统钥匙串或口令包裹；口令路径使用 scrypt。
- 助记词不以明文保存；PIN 使用单向校验值，连续失败锁定；自动登录用系统安全存储并绑定账户/机器。
- 模型 API Key 与社交密码优先系统安全存储；无保护时拒绝静默明文（社交密码会明确标记 `plain`）。
- FWArmy 消息端到端加密（X25519 + HKDF + AES-256-GCM + Ed25519 签名），服务器不存消息。
- 更新包 SHA-256 + 大小校验；工具/脚本调用分级授权，工作区外写入需授权。
- 审计日志本机留存，便于你自查。

**做不到的（请务必理解）：**

- 挡不住已经以你的系统账户运行的恶意软件、键盘记录器、被控制的输入法或远程管理工具。
- 挡不住同一 Windows 账户的其他使用者（DPAPI 会自动解封）；域环境管理员理论上可解 DPAPI。
- 4–20 位 PIN 不是高熵秘密；我们做了限速与锁定，但不能把它变成强密码。
- 挡不住你安装的第三方插件/脚本、你运行的命令、你打开的文件；它们以你的权限运行。
- 挡不住模型服务商、IM 平台、中继运营者按其自身政策记录、训练、跨境或泄露数据。
- 挡不住 AI 输出错误、幻觉、提示词注入或被诱导执行危险操作；关键决策必须人工复核。
- 依赖链（Electron、Node、开源库、模型文件）自身可能存在未公开漏洞；我们没有做第三方安全认证或渗透测试背书。
- 本机明文文件的安全下限就是你的操作系统账户与磁盘加密；请自行开启全盘加密并做好备份。

## 16. 如何删除你的数据

1. **退出应用**（托盘「下班」/退出），确保没有进程占用文件。
2. **删除用户数据目录**：
   - Windows：`%APPDATA%\@warmy\app-shell`
   - macOS：`~/Library/Application Support/@warmy/app-shell`
   - Linux：`${XDG_CONFIG_HOME:-~/.config}/@warmy/app-shell`
   - 若你用 `--user-data-dir=` 启动，删除那个目录。
3. **卸载程序**：卸载器不一定会删除用户数据目录；第 2 步才是彻底删除。
4. **云端模型侧**：到服务商控制台删除对话/文件、吊销 API Key；本机删除不会影响服务商已保存的数据。
5. **GitHub**：编辑或删除你发过的 Issue/评论/PR；需要删除邮件时联系我们。
6. **FWArmy**：停止服务器，删除其 `data/`（`credentials.json`、`stats.json`、`server.log`、`config.json` 等）；如凭据曾泄露，全部吊销重建。
7. **第三方 IM**：在应用内断开连接，并在微信/企微/Telegram/飞书侧解除授权。
8. **导出与备份**：删除你导出的 `.NM` 配置包、身份备份 JSON、Markdown/CSV 导出、截图等；它们在本机数据目录之外，应用不会替你清理。
9. **最近删除**：48 小时后自动清理；想立刻删除就在界面清空。

删除是**不可恢复**的。我们没有服务器副本可以"再删一次"，也没有备份可以恢复。
