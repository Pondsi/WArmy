> 用户口径：**不能提高提示词字数上限；所有语言的上限必须与简体中文相同；简体中文的限制字数不改。**
> 其它语言超限时按中文重新翻译/压缩；因为要减字数，内容不全面、略有区别是正常的，**大意不能变**。
> 本文是现行口径；`docs/PROMPT-LAYERS-R81.md`、`docs/DECISIONS-R81.md` 里“英文上限 9750 / 法文 10400”等按语言放大的数字已作废。

1. **内容变少**：非中文道/术从 43/25 条降到 10–43 / 14–25 条（fr 保留了 43 条）；认知预设从完整结构压到「角色+任务+一条方法+各节首句」。这是用户明确允许的“内容不全面、略有区别”。
2. **大意优先**：保留每节主题与前面的完整规则，不把规则切成半句；没有凭空新增规则。
3. **简体中文没动**：道 2205/2600、术 1901/4200、认知最大 542/1600，均原样。
4. **上限没有提高**：所有语言同一数字；旧的按语言折算系数全部改为 1；总量闸也按原始字符数。
