## #106 会话级网络路由（A）

**现状**：`hui-hua-lu-you.ts` 已有缓存/5 并发/失败剔除；`wangLuo-peiZhi.ts` 已有扇出；**真实发送主路径没接**，FWArmy 中继客户端也没建。

1. **消息身份**：每条人消息生成 UUIDv7 `msgId`；接收端 inbox 按 `msgId` 去重（同一条经多服务器到达只落一次）。
2. **本机 outbox**：`outbox.jsonl` 先写待发（msgId、会话、候选服务器、密文、ts），任一服务器回执后标记 done；重启继续发。
3. **选路**：最近成功 ≤5 优先；失败两次从候选剔除（可恢复）；剩余 5 并发竞速，首个成功取消其余；单次 8s 超时。
4. **全部失败**：消息保持待发、会话只读、UI 显示“未送达/网络不可用”；不写绿勾、不假装成功；网络恢复后自动重试。
5. **只读广播**：向会话成员广播 `network-unavailable`，对端显示只读原因；恢复后广播 `network-ok`。
6. **传输**：接 FWArmy 中继客户端（端到端加密信封）+ 现有 mesh；服务器列表按会话多选。
7. **门禁**：纯逻辑（选路/去重/超时/剔除）、outbox 重启恢复、全失败只读、5 并发首成功取消其余、真实中继回环。

## #108 角色矩阵 + 审批 + 稳定锚点（A）

1. **角色门禁**：creator（唯一，不可移除/降级）> admin（改设置/审批/移除 member）> member（只读+发言）；所有写操作后端再校验，不只看 UI。
2. **审批流**：加入请求进 pending；creator/admin 批准后签发成员证书（groupId/member/expiresAt/supersedes）；拒绝不泄漏群内容；旧邀请在创建者确认后失效。
3. **稳定会话锚点**：每个项目/群/联系人创建时生成一对 Ed25519 `anchorKey`；公钥指纹作为会话锚点，私钥进系统安全存储；换网络/服务器只换地址，锚点不变。
4. **名片 QR**：`node`（锚点指纹）、`prov`（可多选）、`tok`（一次性邀请）、`avatar`；创建者换服务商后重发，旧邀请失效。
5. **UI**：成员列表显示角色；创建者/管理员看到审批与移除；member 不显示管理动作；换机/恢复时锚点随身份备份。
6. **门禁**：角色矩阵真值表、pending 批准/拒绝、锚点换网不变、旧邀请失效、成员无法越权。

## #103 知识库三层授权（A）

1. 每个会话保存三个勾选：**可读 / 可写 / 可归档**，默认按会话类型（群聊=会话层；项目=会话+内部；联系人=会话；我的牛马=三层）。
2. 读：检索/注入前按勾选过滤；写：写入时后端再次校验（前端勾选不可信）；归档：单独校验。
3. 用户切换：只允许在线用户；切换后只展示对方公开层；私密层永不展示。
4. HNS 来源标识：每条结果显示来自哪一层/哪个用户。
5. 门禁：默认矩阵、越权读/写被拒、用户切换只显示公开层、写权限后端复核。
