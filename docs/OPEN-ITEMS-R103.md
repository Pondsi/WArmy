## C. 代码签名 / macOS 公证

**结论**：没有双平台个人开源完全免费且官方认可的方案。

### Windows

- **SignPath Foundation**：$0（合资格 OSS）；能消除“未知发布者”，SmartScreen 首版仍可能提示；证书主体是 Foundation。
  - 需要：公开仓库 URL、OSI 许可证、发布页、CI、维护者权限；不需要个人身份证明。
- Azure Artifact Signing：约 $9.99/月；个人限美国/加拿大；不能立刻消除 SmartScreen。
- OV/EV 证书：$150–400+/年；EV 自 2024 起不再有 SmartScreen 特权。
- Store MSIX：$0 但必须上架 Store。

**推荐**：先申请 SignPath Foundation；如果申请不下来再考虑 Azure/OV。

### macOS

- Developer ID + 公证：**$99/年** Apple Developer Program；能基本消除“无法验证开发者”，首次打开仍有标准确认。
- 免费 Apple ID：只能本机开发签名，不能分发/公证。
- ad-hoc：$0，本机可跑，但**不能公证、不能消除 Gatekeeper 警告**；macOS 15 起右键打开被移除，macOS 26 部分场景无法放行；自动更新不可靠。
- 费用豁免：仅合法非营利/教育/政府，个人不符合。

**推荐**：若坚持 macOS 正式分发，购买 $99/年；否则发布页明确“未公证/实验性”，给 SHA-256 + 系统设置放行步骤，不承诺自动更新。

**需要你提供/拍板**：
1. Windows 是否申请 SignPath Foundation（需要仓库公开、许可证、CI、维护者权限）；
2. macOS 是否购买 Apple Developer Program（$99/年）或接受 ad-hoc 未公证；
3. 若选 ad-hoc，是否要我显式写进 electron-builder 配置并更新发布说明。

**最坏情况**：未签名 Windows 被 SmartScreen/企业策略完全阻止；未签名 macOS arm64 可能直接不启动；ad-hoc 在 macOS 15/26 可能无法放行；关闭 Gatekeeper/SIP 会削弱整机安全，不建议。
