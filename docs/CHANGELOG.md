# CHANGELOG

## 2026-10-04 v0.1.9（新版本）

### 模型能力与调用
- **模型能力识别**：拉取模型时解析端点字段（`input_modalities`/`capabilities`/`supported_parameters`/`context_length`），拿不到用**已知型号表**兜底。识别种类：对话 / 嵌入 / 听话(ASR) / 说话(TTS) / 决策(路由·分类)。
- **思考档位映射**：拉取时按强度比例把模型的档位铺到我们的 l1..l6（3/4/6 档都能正确对应），发请求时按映射表走。
- **上下文长度**：模型标签与调用链里都显示（如 128K / 32K）。
- **调用链只显示支持该用途的模型**；说话模型（TTS）已加入模型选项。
- **叫法（仅简体中文）**：TTS=说话模型、ASR=听话模型、LLM=对话模型；其它语言仍用规范术语。

### 可靠性
- **智能选模型落到真实存在的模型**；只从**已配 Key 或 Ollama** 的模型里挑。
- **调用失败自动降级**：顺着调用链换下一个模型重试（最多 3 个）。
- **Ollama 请求体修正**：`tool_calls.arguments` 改发对象、多模态改走 `images` —— 修掉 `can't find closing '}' symbol`。
- **决策卡音效**：预解码 + 复用 Audio + 失败重试；卡片真的画出来时响。
- **决策卡 X/N**：多个待决时显示序号。

### 验证
`FULL_VERIFY_3X_PASSED`（37 门禁 × 3 轮）。

## 2026-10-03 v0.1.8

### 开箱即用工具面（按授权档位统一设计）
- **受限 shell** `run_shell`：完全授权无限制；严格授权逐条询问（不勾「允许提权」则直接拒绝）；常规授权只放行白名单命令，其余询问。
- **skill 发现/安装** `find_skill` / `install_skill`：装前必过**安全检测**；常规授权下低风险自动装，否则询问。
- **安全检测** `check_safety`：静态扫描 rm -rf / curl|sh / sudo / 密钥外发等危险模式，给 low/medium/high 评级。
- **Office 读** `read_docx` / `read_pptx`；**网络** `fetch_url` / `download_file`（下载可写系统目录，走越权流程）。

### 关键修复
- **Ollama 干不了活的根因**：providers 把 Ollama 硬声明为「不支持工具」，`write_file`/`make_docx`/`open_path` 整层被剥掉。现透传 tools + 解析 tool_calls，不支持的模型由降级链兜住。
- **牛马不知道自己是谁**：身份注入补上模型 id（用户问「你是哪个模型」能如实回答）。
- **动态小字过快**：文案改为每 3 秒轮换（秒数仍每秒走）。
- **「当前使用」概念误导** → 改名「兜底」（真正用哪家由模型决定）。
- **第四列模型管理**：只保留「可用模型 + 调用链」，与牛马管理局一致。
- **消息排版**：微信式气泡自适应换行；⧉ 在对话右下角，悬停时其左侧显示完整时间；跨时主动显示年月日时分秒；跨自然日加浅分隔线。

### 验证
`FULL_VERIFY_3X_PASSED`：37 门禁 × 3 轮全绿。

## 2026-10-03 v0.1.6

### 本轮关键修复
- **HTTP 404 根因**：编辑/拉取**任何**供应商都会 `setProvider`，把「当前生效供应商」劫持成这一家 —— 加个 Ollama 当普通供应商，聊天就切成 Ollama 了。现改为：只有显式点「设为当前使用」才切换；编辑/拉取/点默认模型只在**本就是生效供应商**时才同步。
- **404 二次根因**：`congYuSheChuangJian` 认不出 `ollama-xxx` 这类自定义 id，退化成 openai-compatible 去打 `/chat/completions`（Ollama 返回 404 page not found）。现补上协议透传。
- **截图无法完成（真根因）**：`snip-preload` 用 `ipcRenderer.send`，而 `chuliIpc` 注册在 `ipcMain.handle` —— 消息没人收，确定/取消全无反应。现改走 `invoke`。
- **截图交互**：拖动框选 → 出「确定/取消/整屏」按钮；左键双击＝确定；右键/Esc＝取消；不再松手即截取。

### 模型选项
- 「特殊模型」→「模型选项」；新增「分类模型」调用链（第一个=默认，可上移/下移/禁用）。
- 供应商卡新增「设为当前使用」按钮 + 「当前使用」徽章。

### 验证
- `FULL_VERIFY_3X_PASSED`：34+ 门禁 × 3 轮全绿。
